Instalar el píxel de Meta

Guía para quien administra la web. Primero elige cómo está hecha, y verás solo los pasos que te sirven.

¿Cómo está hecha la web?

Con un constructor web

Aquí no hay que tocar código. Solo se pega un número.

  1. Copia el ID del píxel

    Es el número que identifica nuestro píxel de Meta.

    1778254566808591

  2. Pégalo en tu plataforma

    Abre la tuya y sigue los pasos. Los nombres de los menús pueden cambiar un poco según la versión.

    WordPress
    1. Instala el plugin gratuito Meta para WordPress (Facebook for WordPress).
    2. Conecta la cuenta o elige la opción de ingresar el ID del píxel manualmente.
    3. Pega el ID y guarda.

    Alternativa: con el plugin WPCode, agrega el código completo (pestaña Con código propio) como script en el encabezado.

    Wix
    1. Ve a Marketing y SEO y busca Integraciones de marketing.
    2. Elige Píxel de Meta y toca Conectar.
    3. Pega el ID y guarda.
    Shopify
    1. Ve a Configuración y entra a Aplicaciones y canales de ventas.
    2. Abre el canal Facebook e Instagram y conecta el conjunto de datos (píxel) con el ID.
    3. Guarda los cambios.
    Webflow
    1. Ve a Project settings y abre Custom code.
    2. En Head code pega el código completo (pestaña Con código propio).
    3. Guarda y publica el sitio.
    Squarespace
    1. Ve a Configuración, luego Avanzado y Inserción de código.
    2. En Encabezado pega el código completo (pestaña Con código propio).
    3. Guarda.
    Otra plataforma

    Busca un campo llamado píxel de Facebook, píxel de Meta, scripts de cabecera o código en el head. Si pide solo un número, pega el ID. Si pide código, usa la pestaña Con código propio.

  3. Verifica que funciona

    Instala la extensión gratuita Meta Pixel Helper en Chrome y abre la página del evento. Si el ícono de la extensión se pone en verde, quedó bien.

  2. Pégalo en el head

    Dentro de la etiqueta <head> de la página del evento, antes de </head>. Si lo pones en la plantilla general, quedará en todas las páginas.

  3. Publica y verifica

    Guarda los cambios, publícalos y abre la página del evento con la extensión Meta Pixel Helper de Chrome. Si el ícono se pone en verde, quedó bien.

Si el botón no copia en tu navegador, selecciona el código a mano y cópialo con Ctrl+C (o Cmd+C en Mac).
